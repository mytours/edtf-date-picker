# Phase 1: edtf-input-core Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Scaffold the pnpm monorepo and build `edtf-input-core`: config, model, generator (UI state → EDTF), natural-language parser, bounds, labels and shared fixtures, with no DOM.

**Architecture:** Pure functions over a resolved `Config`. `generate()` and `analyse()` both end in `finish()` (`src/result.ts`), which validates with edtf.js `parse()`, enforces `maxLevel` and min/max, applies config warnings, then labels with edtf-humanize and captions the shape. Bounds come from the edtf.js parse tree, not `edtf().min/max`. The parser turns text into the same `State` the guided UI produces, so "Adjust this using the options above" is just loading that state.

**Tech Stack:** pnpm 10 workspaces, TypeScript 6 (strict, `exactOptionalPropertyTypes`), tsup (ESM only), vitest 5 (projects), fast-check 4, eslint 10 + typescript-eslint strictTypeChecked, prettier 3. Runtime deps: `edtf@4.11.1` (pinned), `edtf-humanize@0.1.0`.

## Things the engineer must know first

**edtf.js (4.11.1) behaviour this code depends on.** All checked by probing; tests pin each one.

| Behaviour                                                                                                                                                        | Consequence here                                                              |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| No TypeScript types; the default export has CJS interop problems in bundlers                                                                                     | Use only the named `parse()` export; types in `src/edtf.d.ts`                 |
| Qualifier next to `X` rejected (`1982-?03-XX`, `XXXX-?03`)                                                                                                       | Drop trailing X parts; otherwise drop qualifiers + warn                       |
| Qualified seasons rejected (`2001-21~`, `2001-~21`); `XXXX-21`, `198X-21` rejected                                                                               | Drop the mark + warn; a season needs a known year                             |
| Seasons can't be interval or set ends (`2001-21/2002`, `[2001-21..]`)                                                                                            | `season-not-allowed` error for range/period ends                              |
| `196/198` rejected but `196X/198X` fine                                                                                                                          | Decade period ends are written `196X`                                         |
| Two-ended set ranges reject qualifiers anywhere (`[~1890..1900]`, `[1890~..1900]`); open-ended sets accept prefixes (`[..~1931]`) but not trailing (`[..1931?]`) | Try natural → prefix form, else drop qualifiers + warn (`firstParsing`)       |
| Set range ends need equal precision (`[1890..2020-12-25]` rejected)                                                                                              | Pad: `[1890-01-01..2020-12-25]`                                               |
| `1890~/1905-05-?03` rejected, `~1890/1905-05-?03` fine                                                                                                           | If either period end needs per-part prefixes, write both ends in prefix form  |
| `1975-02-29` accepted                                                                                                                                            | Impossible-day check is ours                                                  |
| `parse('1966/196X')` succeeds but building the Interval throws `RangeError: invalid upper bound` when the end's earliest day isn't strictly after the start's    | Generator applies that rule; `finish()` catches the RangeError for raw values |
| Open (`1950/..`) and unknown (`1950/`) interval ends both parse to `null`                                                                                        | `bounds()` reads the raw string                                               |
| `min`/`max` wrong for sets (`[1667..1672]` max = end of 1667), `NaN` for long years, 25 ≡ 33 for seasons                                                         | `bounds()` walks the parse tree                                               |
| Syntax errors carry `offset`; grammar failures ("No possible parsings") don't                                                                                    | `invalid-edtf` message with or without a column                               |

**edtf-humanize (0.1.0)** exports `humanize`, `locales`, and `Locale`. Term overrides are a spread locale object. **It lists every member of a set range** (`[1890-01-01..2020-12-25]` → ~47,000 dates), so `src/label.ts` labels sets containing ranges itself until that's fixed upstream.

**Conventions:** ESM with `.js` import suffixes; no `as` casts or `!` assertions (lint forbids them, use `?? fallback` or `.at(-1)`); `exactOptionalPropertyTypes` means build optional fields with conditional spreads (`...(x ? { k: x } : {})`); tests use a fixed clock `new Date(2026, 9, 19, 12)` (local noon) and `locale: 'en-NZ'` unless stated. Commit messages are plain sentences, as in the existing history.

```ts
// edtf.js ships no type declarations. Only what this package uses is declared.
//
// The default export (the edtf() function) is avoided: edtf's CommonJS build
// has no __esModule marker, so bundlers' interop can resolve it to the module
// object. parse() behaves the same from ESM and CommonJS.
declare module 'edtf' {
  export interface Constraints {
    level?: 0 | 1 | 2 | 3
  }

  /** A qualifier is `true` for the whole value, or a bitmask: year 15, month 48, day 192 */
  export type Qualifier = boolean | number

  export interface DateNode {
    type: 'Date'
    level: number
    /** [year, monthIndex (0-11), day] */
    values: number[]
    /** Bitmask of X digits: year 1/2/4/8 per digit, month 48, day 192 */
    unspecified?: number
    approximate?: Qualifier
    uncertain?: Qualifier
  }

  export interface YearNode {
    type: 'Year'
    level: number
    values: [number]
    significant?: number
  }

  export interface DecadeNode {
    type: 'Decade'
    level: number
    values: [number]
    approximate?: boolean
    uncertain?: boolean
  }

  export interface CenturyNode {
    type: 'Century'
    level: number
    values: [number]
    approximate?: boolean
    uncertain?: boolean
  }

  export interface SeasonNode {
    type: 'Season'
    level: number
    /** [year, season code 21-41] */
    values: [number, number]
  }

  export type LeafNode = DateNode | YearNode | DecadeNode | CenturyNode | SeasonNode

  export interface IntervalNode {
    type: 'Interval'
    level: number
    /** null for both open (`..`) and unknown (empty) ends */
    values: [LeafNode | null, LeafNode | null]
  }

  export interface SetNode {
    type: 'Set' | 'List'
    level: number
    /** A two-element array is a range `a..b` */
    values: (LeafNode | [LeafNode, LeafNode])[]
    earlier?: boolean
    later?: boolean
  }

  export type ParseResult = LeafNode | IntervalNode | SetNode

  export function parse(input: string, constraints?: Constraints): ParseResult
}
```

`packages/core/src/dates.ts`:

```ts
export const pad2 = (n: number): string => String(n).padStart(2, '0')

/** ISO 8601 year: four digits for 0-9999, otherwise a sign and at least six digits */
export function isoYear(year: number): string {
  if (year >= 0 && year <= 9999) return String(year).padStart(4, '0')
  return (year < 0 ? '-' : '+') + String(Math.abs(year)).padStart(6, '0')
}

export const isoDate = (year: number, month: number, day: number): string =>
  `${isoYear(year)}-${pad2(month)}-${pad2(day)}`

/** Days in a month of the proleptic Gregorian calendar (month is 1-12) */
export function daysInMonth(year: number, month: number): number {
  const d = new Date(Date.UTC(2000, 0, 1))
  d.setUTCFullYear(year, month, 0)
  return d.getUTCDate()
}

export const isSeason = (month: number): boolean => month >= 21

/** Orders ISO dates, including expanded years like -000500-01-01 */
export function compareIso(a: string, b: string): number {
  const key = (iso: string): number => {
    const m = /^([+-]?\d+)-(\d{2})-(\d{2})$/.exec(iso)
    if (!m) throw new Error(`Not an ISO date: ${iso}`)
    return Number(m[1]) * 10000 + Number(m[2]) * 100 + Number(m[3])
  }
  return key(a) - key(b)
}
```

`packages/core/src/config.ts`:

```ts
import type { Locale } from 'edtf-humanize'
import { isoDate } from './dates.js'

export type Semantics = 'event' | 'period'
export type Level = 0 | 1 | 2
export type DateOrder = 'dmy' | 'mdy'
export type Terms = Partial<Locale['terms']>

/** A year (1826, '1826'), an ISO date ('1826-06-01') or 'today' */
export type LimitInput = number | string

export interface WarnRule {
  readonly before?: LimitInput
  readonly after?: LimitInput
  readonly message: string
}

/** What a host passes in. Every field is optional and has a neutral default. */
export interface ConfigInput {
  readonly semantics?: Semantics
  readonly min?: LimitInput | null
  readonly max?: LimitInput | null
  readonly warn?: readonly WarnRule[]
  readonly maxLevel?: Level | string | null
  readonly locale?: string
  readonly terms?: Terms
  /** The current time; injectable for tests. Defaults to new Date(). */
  readonly now?: Date
}

export interface Limit {
  /** Inclusive ISO date (YYYY-MM-DD) */
  readonly iso: string
  /** How to name the limit in messages */
  readonly label: string
  readonly today: boolean
}

export interface ResolvedWarnRule {
  readonly before: string | null
  readonly after: string | null
  readonly message: string
}

export interface Config {
  readonly semantics: Semantics
  readonly min: Limit | null
  readonly max: Limit | null
  readonly warn: readonly ResolvedWarnRule[]
  readonly maxLevel: Level
  readonly locale: string
  readonly terms: Terms
  readonly now: Date
  /** The order of day and month in slash dates for this locale */
  readonly dateOrder: DateOrder
}

export class ConfigError extends Error {
  override readonly name = 'ConfigError'
}

function todayIso(now: Date): string {
  return isoDate(now.getFullYear(), now.getMonth() + 1, now.getDate())
}

/** `edge` says which end of a year-only limit to use: a min of 1800 means 1800-01-01 */
function resolveLimit(input: LimitInput, edge: 'start' | 'end', now: Date): Limit {
  const raw = String(input).trim()
  if (raw === 'today') return { iso: todayIso(now), label: 'today', today: true }
  if (/^\d{1,4}$/.test(raw)) {
    const year = Number(raw)
    return {
      iso: edge === 'start' ? isoDate(year, 1, 1) : isoDate(year, 12, 31),
      label: raw,
      today: false,
    }
  }
  if (/^\d{4}-\d{2}-\d{2}$/.test(raw)) return { iso: raw, label: raw, today: false }
  throw new ConfigError(`Expected a year, an ISO date or 'today', got ${JSON.stringify(input)}`)
}

function resolveDateOrder(locale: string): DateOrder {
  const types = new Intl.DateTimeFormat(locale)
    .formatToParts(new Date(2000, 11, 31))
    .map((p) => p.type)
  return types.indexOf('month') < types.indexOf('day') ? 'mdy' : 'dmy'
}

function resolveLevel(input: ConfigInput['maxLevel']): Level {
  if (input == null || input === '') return 2
  const level = Number(input)
  if (level === 0 || level === 1 || level === 2) return level
  throw new ConfigError(`maxLevel must be 0, 1 or 2, got ${JSON.stringify(input)}`)
}

export function resolveConfig(input: ConfigInput = {}): Config {
  const now = input.now ?? new Date()
  const locale = input.locale ?? 'en'
  const min = input.min == null || input.min === '' ? null : resolveLimit(input.min, 'start', now)
  const max = input.max == null || input.max === '' ? null : resolveLimit(input.max, 'end', now)
  if (min && max && min.iso > max.iso) throw new ConfigError('min is later than max')
  return {
    semantics: input.semantics ?? 'event',
    min,
    max,
    // A warning applies when the date is entirely before `before` (or after `after`)
    warn: (input.warn ?? []).map((w) => ({
      before: w.before == null ? null : resolveLimit(w.before, 'start', now).iso,
      after: w.after == null ? null : resolveLimit(w.after, 'end', now).iso,
      message: w.message,
    })),
    maxLevel: resolveLevel(input.maxLevel),
    locale,
    terms: input.terms ?? {},
    now,
    dateOrder: resolveDateOrder(locale),
  }
}
```

```ts
import { parse, type LeafNode, type ParseResult } from 'edtf'
import { compareIso, daysInMonth, isoDate } from './dates.js'

/** What is known about one end of a value */
export type EndKind = 'date' | 'open' | 'unknown'

export interface Bounds {
  /** Earliest possible day (ISO), or null when there is no lower bound */
  readonly earliest: string | null
  /** Latest possible day (ISO), or null when there is no upper bound */
  readonly latest: string | null
  readonly start: EndKind
  readonly end: EndKind
}

interface Span {
  readonly earliest: string
  readonly latest: string
}

// [first month, last month, years to add to the last month]. 21-24 follow the
// northern hemisphere; ISO 8601-2 doesn't say which hemisphere they mean.
const SEASONS: Readonly<Record<number, readonly [number, number, number]>> = {
  21: [3, 5, 0], // spring
  22: [6, 8, 0], // summer
  23: [9, 11, 0], // autumn
  24: [12, 2, 1], // winter
  25: [3, 5, 0], // northern spring
  26: [6, 8, 0], // northern summer
  27: [9, 11, 0], // northern autumn
  28: [12, 2, 1], // northern winter
  29: [9, 11, 0], // southern spring
  30: [12, 2, 1], // southern summer
  31: [3, 5, 0], // southern autumn
  32: [6, 8, 0], // southern winter
  33: [1, 3, 0], // first quarter
  34: [4, 6, 0], // second quarter
  35: [7, 9, 0], // third quarter
  36: [10, 12, 0], // fourth quarter
  37: [1, 4, 0], // first third
  38: [5, 8, 0], // second third
  39: [9, 12, 0], // last third
  40: [1, 6, 0], // first half
  41: [7, 12, 0], // second half
}

const years = (from: number, to: number): Span => ({
  earliest: isoDate(from, 1, 1),
  latest: isoDate(to, 12, 31),
})

const month = (year: number, m: number): Span => ({
  earliest: isoDate(year, m, 1),
  latest: isoDate(year, m, daysInMonth(year, m)),
})

/** Bits of DateNode.unspecified: one per year digit, then month, then day */
const YEAR_DIGITS = [1, 2, 4, 8] as const
const MONTH_X = 48
const DAY_X = 192

function leafSpan(node: LeafNode): Span | null {
  switch (node.type) {
    case 'Year': {
      const [y] = node.values
      if (!node.significant) return years(y, y)
      const digits = String(Math.abs(y)).length
      const size = 10 ** Math.max(0, digits - node.significant)
      const from = Math.floor(y / size) * size
      return years(from, from + size - 1)
    }
    case 'Decade':
      return years(node.values[0] * 10, node.values[0] * 10 + 9)
    case 'Century':
      return years(node.values[0] * 100, node.values[0] * 100 + 99)
    case 'Season': {
      const [y, code] = node.values
      const s = SEASONS[code]
      if (!s) return years(y, y)
      return {
        earliest: isoDate(y, s[0], 1),
        latest: isoDate(y + s[2], s[1], daysInMonth(y + s[2], s[1])),
      }
    }
    case 'Date': {
      const [y = 0, m0, d] = node.values
      const un = node.unspecified ?? 0
      // The first unspecified year digit sets the span: 189X → 10 years, 18XX → 100
      const firstX = YEAR_DIGITS.findIndex((bit) => (un & bit) !== 0)
      if (firstX === 0) return null
      if (firstX > 0) return years(y, y + 10 ** (4 - firstX) - 1)
      if (m0 == null || un & MONTH_X) return years(y, y)
      if (d == null || un & DAY_X) return month(y, m0 + 1)
      const iso = isoDate(y, m0 + 1, d)
      return { earliest: iso, latest: iso }
    }
  }
}

const min = (a: string, b: string): string => (compareIso(a, b) <= 0 ? a : b)
const max = (a: string, b: string): string => (compareIso(a, b) >= 0 ? a : b)

/** The text either side of the interval's slash: '' is unknown, '..' is open */
function intervalEnd(text: string): EndKind {
  const t = text.trim()
  return t === '' ? 'unknown' : t === '..' ? 'open' : 'date'
}

/** Bounds of an already parsed value. `input` is needed to tell open from unknown interval ends. */
export function boundsOf(tree: ParseResult, input: string): Bounds {
  switch (tree.type) {
    case 'Interval': {
      const slash = input.indexOf('/')
      const startKind = intervalEnd(input.slice(0, slash))
      const endKind = intervalEnd(input.slice(slash + 1))
      const a = tree.values[0] ? leafSpan(tree.values[0]) : null
      const b = tree.values[1] ? leafSpan(tree.values[1]) : null
      return {
        earliest: a?.earliest ?? null,
        latest: b?.latest ?? null,
        start: a ? 'date' : startKind === 'date' ? 'unknown' : startKind,
        end: b ? 'date' : endKind === 'date' ? 'unknown' : endKind,
      }
    }
    case 'Set':
    case 'List': {
      const spans = tree.values
        .flatMap((v) => (Array.isArray(v) ? [leafSpan(v[0]), leafSpan(v[1])] : [leafSpan(v)]))
        .filter((s): s is Span => s != null)
      if (spans.length === 0)
        return { earliest: null, latest: null, start: 'unknown', end: 'unknown' }
      const earliest = spans.map((s) => s.earliest).reduce(min)
      const latest = spans.map((s) => s.latest).reduce(max)
      return {
        earliest: tree.earlier ? null : earliest,
        latest: tree.later ? null : latest,
        start: tree.earlier ? 'open' : 'date',
        end: tree.later ? 'open' : 'date',
      }
    }
    default: {
      const span = leafSpan(tree)
      if (!span) return { earliest: null, latest: null, start: 'unknown', end: 'unknown' }
      return { ...span, start: 'date', end: 'date' }
    }
  }
}

/** Earliest and latest possible days of an EDTF value. Throws if the value isn't valid EDTF. */
export function bounds(value: string): Bounds {
  return boundsOf(parse(value), value)
}
```

`packages/core/src/label.ts`:

```ts
import type { ParseResult, SetNode } from 'edtf'
import { humanize, locales, type Locale, type LocaleCode } from 'edtf-humanize'
import type { Bounds } from './bounds.js'
import type { Config } from './config.js'

function humanizeLocale(config: Config): Locale {
  const language = config.locale.toLowerCase().split('-')[0] ?? 'en'
  const base = language in locales ? locales[language as LocaleCode] : locales.en
  return { ...base, terms: { ...base.terms, ...config.terms } }
}

/**
 * edtf-humanize 0.1.0 lists every member of a set range, so
 * [1890-01-01..2020-12-25] becomes ~47,000 dates. Until that is fixed
 * upstream, label sets containing a range here: each range as an interval
 * ("1890 to 1905"), joined with the locale's set connectors.
 */
function setWithRangesLabel(tree: SetNode, value: string, locale: Locale): string | null {
  if (!tree.values.some(Array.isArray)) return null
  const terms = tree.type === 'Set' ? locale.terms.exclusiveSet : locale.terms.inclusiveSet
  const h = (v: string) => humanize(v, { locale })
  const items = value
    .slice(1, -1)
    .split(',')
    .map((member) => {
      const m = member.trim()
      if (m.startsWith('..')) return terms.earlierPrefix + h(m.slice(2))
      if (m.endsWith('..')) return terms.laterPrefix + h(m.slice(0, -2))
      const range = m.split('..')
      return range.length === 2 ? h(`${range[0] ?? ''}/${range[1] ?? ''}`) : h(m)
    })
  if (items.length === 1) return items[0] ?? null
  if (items.length === 2) return items.join(terms.twoDatesConnector)
  return (
    items.slice(0, -1).join(terms.datesConnector) + terms.lastDateConnector + (items.at(-1) ?? '')
  )
}

/** The human-readable label, from edtf-humanize */
export function labelOf(value: string, tree: ParseResult, config: Config): string {
  const locale = humanizeLocale(config)
  if (tree.type === 'Set' || tree.type === 'List') {
    const label = setWithRangesLabel(tree, value, locale)
    if (label != null) return label
  }
  return humanize(value, { locale })
}

const isQualified = (q: boolean | number | undefined): boolean =>
  q === true || (typeof q === 'number' && q > 0)

/** One line explaining the shape of the value (not the date itself) */
export function captionOf(tree: ParseResult, b: Bounds): string {
  if (b.start === 'unknown' && b.end === 'unknown' && tree.type !== 'Interval')
    return 'That’s fine. It can be filled in later.'
  switch (tree.type) {
    case 'Interval':
      if (b.end === 'open') return 'A span that is still going.'
      if (b.start === 'open') return 'A span with no set start.'
      if (b.end === 'unknown') return 'A span that did end, but when isn’t known.'
      if (b.start === 'unknown') return 'A span that did start, but when isn’t known.'
      return 'A span from the start to the end.'
    case 'Set':
      if (b.start === 'open') return 'One moment, any time up to then.'
      if (b.end === 'open') return 'One moment, any time from then on.'
      return 'One moment, somewhere in this range.'
    case 'List':
      return 'All of these dates.'
    case 'Decade':
      return 'The whole decade.'
    case 'Century':
      return 'The whole century.'
    case 'Season':
      return 'Sometime that season.'
    case 'Year':
      return tree.significant ? 'An estimate, somewhere in this range.' : 'Sometime that year.'
    case 'Date': {
      const approx = isQualified(tree.approximate)
      const uncertain = isQualified(tree.uncertain)
      const perPart = typeof tree.approximate === 'number' || typeof tree.uncertain === 'number'
      if (perPart) return 'Some parts are rough or not certain.'
      if (approx && uncertain) return 'Roughly then, and a best guess.'
      if (approx) return 'Roughly then. It could be a little either side.'
      if (uncertain) return 'A best guess. It might not be right.'
      if ((tree.unspecified ?? 0) & 15) return 'One moment, sometime in that span.'
      const [, m, d] = tree.values
      if (m == null) return 'Sometime that year.'
      if (d == null) return 'Sometime that month.'
      return 'A single day.'
    }
  }
}
```

```ts
export type Status = 'valid' | 'incomplete' | 'invalid'

/** The outcome of generating or analysing a value. Also the `edtf-change` event detail. */
export interface Result {
  readonly status: Status
  readonly value: string | null
  readonly level: Level | null
  readonly label: string | null
  readonly caption: string | null
  readonly earliest: string | null
  readonly latest: string | null
  readonly start: EndKind | null
  readonly end: EndKind | null
  readonly warnings: readonly Message[]
  /** Things the parser assumed, like the order of a slash date */
  readonly notes: readonly Message[]
  readonly error: Message | null

const EMPTY = {
  value: null,
  level: null,
  label: null,
  caption: null,
  earliest: null,
  latest: null,
  start: null,
  end: null,
  warnings: [],
  notes: [],
} as const

export const incomplete = (error: Message): Result => ({ ...EMPTY, status: 'incomplete', error })
export const invalid = (error: Message, warnings: readonly Message[] = []): Result => ({
  ...EMPTY,
  status: 'invalid',
  error,
  warnings,
})

/** Where an edtf.js syntax error points. Grammar-level failures have no position. */
export function parseErrorMessage(error: unknown, value: string): Message {
  const offset = (error as { offset?: unknown } | null)?.offset
  if (typeof offset !== 'number') return message('invalid-edtf', { column: null })
  return message('invalid-edtf', { column: offset + 1, character: value[offset] ?? '' })
}

/**
 * Checks a value against edtf.js, the level limit and the date limits, then
 * labels it. `onParseError` decides what a value edtf.js rejects means.
 */
export function finish(
  value: string,
  config: Config,
  warnings: readonly Message[],
  onParseError: (error: unknown) => Message,
): Result {
  let tree: ParseResult
  try {
    tree = parse(value)
  } catch (e) {
    return invalid(onParseError(e), warnings)
  }
  const level = tree.level as Level
  if (level > config.maxLevel)
    return invalid(message('level-too-high', { level, maxLevel: config.maxLevel }), warnings)

  const b = boundsOf(tree, value)
  if (config.min && b.latest != null && compareIso(b.latest, config.min.iso) < 0)
    return invalid(
      message('before-min', { min: config.min.label, today: config.min.today }),
      warnings,
    )
  if (config.max && b.earliest != null && compareIso(b.earliest, config.max.iso) > 0)
    return invalid(
      message('after-max', { max: config.max.label, today: config.max.today }),
      warnings,
    )

  const all = [...warnings]
  for (const rule of config.warn) {
    const before = rule.before != null && b.latest != null && compareIso(b.latest, rule.before) < 0
    const after = rule.after != null && b.earliest != null && compareIso(b.earliest, rule.after) > 0
    if (before || after) all.push(message('config-warning', { message: rule.message }))
  }

  let label: string
  try {
    label = labelOf(value, tree, config)
  } catch (e) {
    // edtf.js parses 1966/196X but throws when building the interval
    if (e instanceof RangeError && /invalid (upper|lower) bound/.test(e.message))
      return invalid(message('end-before-start'), all)
    throw e
  }

  return {
    status: 'valid',
    value,
    level,
    label,
    caption: captionOf(tree, b),
    earliest: b.earliest,
    latest: b.latest,
    start: b.start,
    end: b.end,
    warnings: all,
    notes: [],
    error: null,
  }
}
```

```ts
  /** null while the field is empty */
  readonly value: number | null
  readonly certainty: Certainty
}

 * The parts of one date. `month` is 1-12, or a season 21-24.
 * Leave `month` out for year precision, and `day` out for month precision.
 */

  readonly year: Part
  readonly month?: Part
  readonly day?: Part
}

export type DecadePart = 'any' | 'early' | 'mid' | 'late'

  | { readonly kind: 'date'; readonly parts: DateParts }
  | { readonly kind: 'decade'; readonly decade: number; readonly part: DecadePart }
  | { readonly kind: 'between'; readonly from: DateParts; readonly to: DateParts }
  | { readonly kind: 'beforeAfter'; readonly dir: 'before' | 'after'; readonly at: DateParts }
  | { readonly kind: 'unknown' }

export type Endpoint =
  | { readonly kind: 'date'; readonly parts: DateParts }
  | { readonly kind: 'decade'; readonly decade: number }
  | { readonly kind: 'unknown' }
  | { readonly kind: 'open' }

export interface PeriodState {
  readonly kind: 'period'
  readonly start: Endpoint
  readonly end: Endpoint
}

export type State = EventState | PeriodState

/** Shorthand for building parts in code and tests */
export const part = (value: number | null, certainty: Certainty = 'sure'): Part => ({
  value,
  certainty,
})
```

```ts
import { message, type Message } from './messages.js'
import type { Certainty, DateParts, Endpoint, EventState, PeriodState, State } from './model.js'
import { finish, incomplete, invalid, type Result } from './result.js'

type Kind = 'year' | 'month' | 'day'
type Qualifier = Exclude<Certainty, 'unknown'>

const SUFFIX: Readonly<Record<Qualifier, string>> = {
  sure: '',
  approximate: '~',
  uncertain: '?',
  both: '%',
}
const WIDTH: Readonly<Record<Kind, number>> = { year: 4, month: 2, day: 2 }

/** One date written out, in each form EDTF allows for it */
interface Written {
  /** Trailing qualifier where possible (1982-03-12~), otherwise per-part prefixes */
  readonly natural: string
  /** Per-part prefixes throughout (~1982-~03-~12) */
  readonly prefix: string
  /** No qualifiers at all */
  readonly plain: string
  readonly qualified: boolean
  readonly warnings: readonly Message[]
  /** Known parts, for padding set ends to equal precision */
  readonly year: number | null
  readonly month: number | null
  readonly day: number | null
}

type Outcome<T> = { ok: T } | { result: Result }

const fail = (r: Result): { result: Result } => ({ result: r })

/** The parts that are present, in order */
function kindsOf(parts: DateParts): Kind[] {
  return parts.day ? ['year', 'month', 'day'] : parts.month ? ['year', 'month'] : ['year']
}

/** Validates the parts and writes them out. `end` scopes messages to one end of a period. */
function writeParts(parts: DateParts, end?: 'start' | 'end'): Outcome<Written> | 'all-unknown' {
  const scope = end ? { end } : {}
  const kinds = kindsOf(parts)
  const value: Record<Kind, number | null> = { year: null, month: null, day: null }
  const q: Record<Kind, Qualifier> = { year: 'sure', month: 'sure', day: 'sure' }

  for (const k of kinds) {
    const p = parts[k]
    if (!p || p.certainty === 'unknown') continue
    if (p.value == null) return fail(incomplete(message('missing', { part: k, ...scope })))
    value[k] = p.value
    q[k] = p.certainty
  }

  const { year, month, day } = value
  if (year != null && (!Number.isInteger(year) || year < 0 || year > 9999))
    return fail(invalid(message('invalid-year', scope)))
  if (
    month != null &&
    !(Number.isInteger(month) && ((month >= 1 && month <= 12) || (month >= 21 && month <= 24)))
  )
    return fail(invalid(message('invalid-month', scope)))
  if (month != null && isSeason(month) && kinds.includes('day'))
    return fail(invalid(message('season-with-day', scope)))
  // edtf.js rejects XXXX-21 and 198X-21
  if (month != null && isSeason(month) && year == null)
    return fail(invalid(message('season-needs-year', scope)))
  if (day != null && month != null) {
    // With no year, allow 29 February
    const days = daysInMonth(year ?? 2000, month)
    if (!Number.isInteger(day) || day < 1 || day > days)
      return fail(invalid(message('impossible-day', { day, month, year, days, ...scope })))
  }

  const known = kinds.filter((k) => value[k] != null)
  if (known.length === 0) return 'all-unknown'

  const warnings: Message[] = []
  let out = kinds
  if (known.some((k) => q[k] !== 'sure')) {
    // A qualifier can't sit next to an X part, so drop trailing unknown parts.
    while (out.length > 1 && value[out.at(-1) ?? 'year'] == null) out = out.slice(0, -1)
    const season = month != null && isSeason(month)
    if (season || out.some((k) => value[k] == null)) {
      for (const k of known) q[k] = 'sure'
      out = kinds
      warnings.push(message('qualifier-dropped', { reason: season ? 'season' : 'unknown-part' }))
    }
  }

  const digits = (k: Kind): string => {
    const v = value[k]
    return v == null ? 'X'.repeat(WIDTH[k]) : String(v).padStart(WIDTH[k], '0')
  }
  const plain = out.map(digits).join('-')
  const prefix = out.map((k) => (value[k] == null ? '' : SUFFIX[q[k]]) + digits(k)).join('-')
  const qs = known.filter((k) => out.includes(k)).map((k) => q[k])
  const uniform = qs.every((x) => x === qs[0])
  const allKnown = out.every((k) => value[k] != null)
  const natural = uniform && allKnown ? plain + SUFFIX[qs[0] ?? 'sure'] : prefix

  return {
    ok: {
      natural,
      prefix,
      plain,
      qualified: qs.some((x) => x !== 'sure'),
      warnings,
      year: out.includes('year') ? year : null,
      month: out.includes('month') ? month : null,
      day: out.includes('day') ? day : null,
    },
  }
}

/** Writes an end of a range, period or before/after, where the year must be known and seasons can't be used */
function writeEnd(parts: DateParts, end?: 'start' | 'end'): Outcome<Written> {
  const scope = end ? { end } : {}
  if (parts.year.certainty === 'unknown')
    return fail(invalid(message('missing', { part: 'year', ...scope })))
  const w = writeParts(parts, end)
  if (w === 'all-unknown') return fail(invalid(message('missing', { part: 'year', ...scope })))
  if ('result' in w) return w
  if (w.ok.month != null && isSeason(w.ok.month))
    return fail(invalid(message('season-not-allowed', scope)))
  return w
}

const parses = (value: string): boolean => {
  try {
    parse(value)
    return true
  } catch {
    return false
  }
}

/**
 * Picks the first candidate edtf.js accepts. edtf.js is inconsistent about
 * qualifiers inside sets ([..~1931] parses, [~1890..1900] doesn't), so the
 * fallback is to drop the qualifiers and say so. If nothing parses, the last
 * candidate is returned and finish() reports it as an internal error.
 */
function firstParsing(
  candidates: readonly string[],
  unqualified: string,
  warn: boolean,
): [string, Message[]] {
  for (const c of candidates) if (parses(c)) return [c, []]
  return [unqualified, warn ? [message('qualifier-dropped', { reason: 'not-supported' })] : []]
}

/** Pads a date to day precision, at the start or end of its period */
function padTo(w: Written, precision: number, edge: 'start' | 'end'): string {
  const y = w.year ?? 0
  const m = w.month ?? (edge === 'start' ? 1 : 12)
  const d = w.day ?? (edge === 'start' ? 1 : daysInMonth(y, m))
  return [String(y).padStart(4, '0'), pad2(m), pad2(d)].slice(0, precision).join('-')
}

const precisionOf = (w: Written): number => (w.day != null ? 3 : w.month != null ? 2 : 1)

const internal = (value: string) => message('internal', { value })

function done(value: string, config: Config, warnings: readonly Message[]): Result {
  return finish(value, config, warnings, () => internal(value))
}

const DECADE_PARTS = { any: [0, 9], early: [0, 3], mid: [4, 6], late: [7, 9] } as const

/** The year of an ISO date, which may have an expanded year (-000500-01-01) */
const yearOf = (iso: string | undefined): number | null =>
  iso == null ? null : Number(iso.slice(0, -6))

function generateEvent(state: EventState, config: Config): Result {
  switch (state.kind) {
    case 'unknown':
      return done('XXXX', config, [])

    case 'date': {
      const w = writeParts(state.parts)
      if (w === 'all-unknown') return done('XXXX', config, [])
      if ('result' in w) return w.result
      return done(w.ok.natural, config, w.ok.warnings)
    }

    case 'decade': {
      const d = state.decade
      if (!Number.isInteger(d) || d % 10 !== 0 || d < 0 || d > 9990)
        return invalid(message('decade-not-zero', { suggestion: Math.max(0, d - (d % 10)) }))
      const stem = String(d / 10).padStart(3, '0')
      if (state.part === 'any') return done(`${stem}X`, config, [])
      const [a, b] = DECADE_PARTS[state.part]
      const minY = yearOf(config.min?.iso)
      const maxY = yearOf(config.max?.iso)
      const lo = Math.max(d + a, minY ?? -Infinity)
      const hi = Math.min(d + b, maxY ?? Infinity)
      if (lo > hi) return invalid(message('outside-limits'))
      const y = (n: number) => String(n).padStart(4, '0')
      return done(lo === hi ? y(lo) : `[${y(lo)}..${y(hi)}]`, config, [])
    }

    case 'between': {
      const a = writeEnd(state.from)
      if ('result' in a) return a.result
      const b = writeEnd(state.to)
      if ('result' in b) return b.result
      // Set ranges need both ends at the same precision
      const p = Math.max(precisionOf(a.ok), precisionOf(b.ok))
      const from = padTo(a.ok, p, 'start')
      const to = padTo(b.ok, p, 'end')
      if (compareIso(bounds(from).earliest ?? '', bounds(to).latest ?? '') > 0)
        return invalid(message('from-after-to'))
      if (from === to) return done(a.ok.natural, config, a.ok.warnings)
      const qualified = a.ok.qualified || b.ok.qualified
      const warnings = [...a.ok.warnings, ...b.ok.warnings]
      if (!qualified) return done(`[${from}..${to}]`, config, warnings)
      // Qualifiers only survive when no padding was needed
      const same = precisionOf(a.ok) === precisionOf(b.ok)
      const candidates = same
        ? [`[${a.ok.natural}..${b.ok.natural}]`, `[${a.ok.prefix}..${b.ok.prefix}]`]
        : []
      const [value, extra] = firstParsing(candidates, `[${from}..${to}]`, true)
      return done(value, config, [...warnings, ...extra])
    }

    case 'beforeAfter': {
      const w = writeEnd(state.at)
      if ('result' in w) return w.result
      const wrap = (s: string) => (state.dir === 'before' ? `[..${s}]` : `[${s}..]`)
      const [value, extra] = firstParsing(
        [wrap(w.ok.natural), wrap(w.ok.prefix)],
        wrap(w.ok.plain),
        w.ok.qualified,
      )
      return done(value, config, [...w.ok.warnings, ...extra])
    }
  }
}

type WrittenEnd = { kind: 'date'; w: Written } | { kind: 'open' } | { kind: 'unknown' }

function writeEndpoint(e: Endpoint, end: 'start' | 'end'): Outcome<WrittenEnd> {
  switch (e.kind) {
    case 'open':
    case 'unknown':
      return { ok: { kind: e.kind } }
    case 'decade': {
      const d = e.decade
      if (!Number.isInteger(d) || d % 10 !== 0 || d < 0 || d > 9990)
        return fail(
          invalid(message('decade-not-zero', { suggestion: Math.max(0, d - (d % 10)), end })),
        )
      // A decade can't be an interval end (196/198 doesn't parse), but 196X can
      const text = `${String(d / 10).padStart(3, '0')}X`
      return {
        ok: {
          kind: 'date',
          w: {
            natural: text,
            prefix: text,
            plain: text,
            qualified: false,
            warnings: [],
            year: d,
            month: null,
            day: null,
          },
        },
      }
    }
    case 'date': {
      const w = writeEnd(e.parts, end)
      if ('result' in w) return w
      return { ok: { kind: 'date', w: w.ok } }
    }
  }
}

function generatePeriod(state: PeriodState, config: Config): Result {
  const a = writeEndpoint(state.start, 'start')
  if ('result' in a) return a.result
  const b = writeEndpoint(state.end, 'end')
  if ('result' in b) return b.result
  const s = a.ok
  const e = b.ok
  if (s.kind !== 'date' && e.kind !== 'date') return invalid(message('period-needs-a-date'))

  if (s.kind === 'date' && e.kind === 'date') {
    if (s.w.natural === e.w.natural) return done(s.w.natural, config, s.w.warnings)
    // edtf.js needs the end to start strictly after the start does, so
    // 1965-06/1965 and 1966/196X are rejected even though they overlap
    const startFrom = bounds(s.w.plain).earliest
    const endFrom = bounds(e.w.plain).earliest
    if (startFrom && endFrom && compareIso(startFrom, endFrom) >= 0)
      return invalid(message('end-before-start'))
  }

  const text = (x: WrittenEnd, form: 'natural' | 'prefix' | 'plain'): string =>
    x.kind === 'open' ? '..' : x.kind === 'unknown' ? '' : x.w[form]
  const warnings = [s, e].flatMap((x) => (x.kind === 'date' ? x.w.warnings : []))
  const qualified = [s, e].some((x) => x.kind === 'date' && x.w.qualified)
  // edtf.js rejects a trailing qualifier on one end with prefixes on the other
  // (1890~/1905-05-?03), so if either end needs prefixes, write both that way.
  const needsPrefix = [s, e].some(
    (x) => x.kind === 'date' && x.w.qualified && x.w.natural === x.w.prefix,
  )
  const candidates = needsPrefix
    ? [`${text(s, 'prefix')}/${text(e, 'prefix')}`]
    : [`${text(s, 'natural')}/${text(e, 'natural')}`, `${text(s, 'prefix')}/${text(e, 'prefix')}`]
  const [value, extra] = firstParsing(
    candidates,
    `${text(s, 'plain')}/${text(e, 'plain')}`,
    qualified,
  )
  return done(value, config, [...warnings, ...extra])
}

/** Turns guided UI state into an EDTF value, checked with edtf.js */
export function generate(state: State, config: Config): Result {
  return state.kind === 'period' ? generatePeriod(state, config) : generateEvent(state, config)
}
```

Order matters in `parseText`: before/after/onwards first (so "from 1975 onwards" isn't read as a range), then a single expression, then a two-sided range. `anyOf()` sorts alternatives longest first so "up to" beats "up". Qualifiers apply per side, so "about 1890 to 1905" marks only the start.

```ts
/** Lower case, straight quotes, plain hyphens, single spaces */
export function normalise(text: string): string {
  return text
    .toLowerCase()
    .replace(/[’‘`]/g, "'")
    .replace(/[“”]/g, '"')
    .replace(/[–—]/g, '-')
    .replace(/\s+/g, ' ')
    .trim()
}

const escape = (s: string): string => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')

export const anyOf = (words: readonly string[]): string =>
  [...words]
```

```ts
import type { Config } from '../config.js'
import { compareIso, isoDate } from '../dates.js'
import { message, type Message } from '../messages.js'
import { part, type Certainty, type DateParts, type DecadePart } from '../model.js'
import { anyOf } from './normalise.js'
import { en } from './vocab/en.js'

/** One date expression: a date, a decade, or "don't know" */
export type Single =
  | { readonly kind: 'date'; readonly parts: DateParts }
  | { readonly kind: 'decade'; readonly decade: number; readonly part: DecadePart }
  | { readonly kind: 'unknown' }

/** null means "not a single date expression"; the caller may try other forms */
export type Parsed<T> =
  { readonly value: T; readonly notes: readonly Message[] } | { readonly error: Message } | null

const APPROX_BEFORE = new RegExp(`^(?:${anyOf(en.approximateBefore)})(?:\\s+|(?=\\d))`)
const APPROX_AFTER = new RegExp(`(?:${anyOf(en.approximateAfter)})$`)
const UNCERTAIN_WORDS = new RegExp(`\\b(?:${anyOf(en.uncertainWords)})\\b`, 'g')
const UNKNOWN = new RegExp(`^(?:${anyOf(en.unknown)})$`)
const SEASON = new RegExp(`^(${anyOf(Object.keys(en.seasons))})(?: of)? (\\d{4})$`)
const DECADE = new RegExp(
  `^(?:the )?(?:(${anyOf(Object.keys(en.decadeParts))})[ -]?)?(?:the )?(\\d{4}|'?\\d{2})'?s$`,
)

/** Strips qualifier words and returns how sure the text is */
export function qualifiers(text: string): { text: string; certainty: Certainty } {
  let t = text
  let uncertain = false
  let approximate = false
  if (/\?+$/.test(t) || new RegExp(UNCERTAIN_WORDS.source).test(t)) {
    uncertain = true
    t = t.replace(/\?+$/, '').replace(UNCERTAIN_WORDS, '').replace(/\s+/g, ' ').trim()
  }
  if (APPROX_BEFORE.test(t)) {
    approximate = true
    t = t.replace(APPROX_BEFORE, '').trim()
  }
  if (APPROX_AFTER.test(t)) {
    approximate = true
    t = t.replace(APPROX_AFTER, '').trim()
  }
  const certainty =
    approximate && uncertain
      ? 'both'
      : approximate
        ? 'approximate'
        : uncertain
          ? 'uncertain'
          : 'sure'
  return { text: t, certainty }
}

/** 1-12 for a month name or abbreviation of at least three letters, else 0 */
export function monthNumber(word: string): number {
  if (word.length < 3) return 0
  return en.months.findIndex((m) => m.startsWith(word)) + 1
}

/** '60s → the most recent allowed decade ending in 60, with a note naming the other */
function twoDigitDecade(n: number, config: Config): { decade: number; notes: Message[] } {
  const allowed = (d: number) =>
    (!config.min || compareIso(isoDate(d + 9, 12, 31), config.min.iso) >= 0) &&
    (!config.max || compareIso(isoDate(d, 1, 1), config.max.iso) <= 0)
  const options = [1900 + n, 2000 + n].filter(allowed)
  if (options.length === 0) return { decade: 1900 + n, notes: [] }
  const thisYear = config.now.getFullYear()
  const past = options.filter((d) => d <= thisYear)
  const decade = past.at(-1) ?? options[0] ?? 1900 + n
  const other = options.find((d) => d !== decade)
  return {
    decade,
    notes: other == null ? [] : [message('two-digit-decade', { decade, alternative: other })],
  }
}

const withCertainty = (parts: DateParts, c: Certainty): DateParts => ({
  year: { ...parts.year, certainty: c },
  ...(parts.month ? { month: { ...parts.month, certainty: c } } : {}),
  ...(parts.day ? { day: { ...parts.day, certainty: c } } : {}),
})

const date = (year: number, month?: number, day?: number): DateParts => ({
  year: part(year),
  ...(month != null ? { month: part(month) } : {}),
  ...(day != null ? { day: part(day) } : {}),
})

const formatDay = (locale: string, year: number, month: number, day: number): string =>
  new Intl.DateTimeFormat(locale, {
    day: 'numeric',
    month: 'long',
    year: 'numeric',
    timeZone: 'UTC',
  }).format(new Date(Date.UTC(year, month - 1, day)))

/** Parses one date expression, with its qualifiers */
export function parseSingle(raw: string, config: Config): Parsed<Single> {
  if (UNKNOWN.test(raw)) return { value: { kind: 'unknown' }, notes: [] }
  const { text: t, certainty } = qualifiers(raw)
  const ok = (parts: DateParts, notes: Message[] = []) => ({
    value: { kind: 'date' as const, parts: withCertainty(parts, certainty) },
    notes,
  })
  let m: RegExpExecArray | null

  if ((m = DECADE.exec(t))) {
    const decadePart = m[1] ? (en.decadeParts[m[1]] ?? 'any') : 'any'
    const digits = (m[2] ?? '').replace("'", '')
    let decade = Number(digits)
    let notes: Message[] = []
    if (digits.length === 2) ({ decade, notes } = twoDigitDecade(decade, config))
    if (decade % 10 !== 0)
      return { error: message('decade-not-zero', { suggestion: decade - (decade % 10) }) }
    return { value: { kind: 'decade', decade, part: decadePart }, notes }
  }

  if ((m = SEASON.exec(t))) return ok(date(Number(m[2]), en.seasons[m[1] ?? '']))

  // 12 March 1982, 12th of March, 1982
  if ((m = /^(\d{1,2})(?:st|nd|rd|th)?(?: of)? ([a-z]+)\.?,? (\d{4})$/.exec(t))) {
    const month = monthNumber(m[2] ?? '')
    if (month) return ok(date(Number(m[3]), month, Number(m[1])))
  }
  // March 12, 1982
  if ((m = /^([a-z]+)\.? (\d{1,2})(?:st|nd|rd|th)?,? (\d{4})$/.exec(t))) {
    const month = monthNumber(m[1] ?? '')
    if (month) return ok(date(Number(m[3]), month, Number(m[2])))
  }
  // March 1982, March of 1982
  if ((m = /^([a-z]+)\.?,?(?: of)? (\d{4})$/.exec(t))) {
    const month = monthNumber(m[1] ?? '')
    if (month) return ok(date(Number(m[2]), month))
  }
  // 1982-03-12, 1982-03
  if ((m = /^(\d{4})-(\d{2})(?:-(\d{2}))?$/.exec(t))) {
    const month = Number(m[2])
    if (month < 1 || month > 12) return { error: message('invalid-month') }
    return ok(date(Number(m[1]), month, m[3] ? Number(m[3]) : undefined))
  }
  // 3/4/1975 or 3.4.1975, in the locale's order
  if ((m = /^(\d{1,2})[/.](\d{1,2})[/.](\d{4})$/.exec(t))) {
    const first = Number(m[1])
    const second = Number(m[2])
    const year = Number(m[3])
    const [day, month] = config.dateOrder === 'mdy' ? [second, first] : [first, second]
    if (month < 1 || month > 12)
      return { error: message('slash-order-mismatch', { order: config.dateOrder }) }
    const ambiguous = first <= 12 && second <= 12 && first !== second
    const notes = ambiguous
      ? [
          message('slash-order-assumed', {
            order: config.dateOrder,
            date: formatDay(config.locale, year, month, day),
          }),
        ]
      : []
    return ok(date(year, month, day), notes)
  }
  if (/^\d{4}$/.test(t)) return ok(date(Number(t)))

  return null
}
```

```ts
const AFTER = new RegExp(`^(?:${anyOf(en.after)}) (.+?)(?: (?:${anyOf(en.onwards)}))?$`)
const ONWARDS = new RegExp(`^(.+?) ?(?:${anyOf(en.onwards)})$`)
const BEFORE = new RegExp(`^(?:${anyOf(en.before)}) (.+)$`)
const RANGE_START = new RegExp(`^(?:${anyOf(en.rangeStart)}) `)
const CONNECTIVE = new RegExp(` (?:${anyOf(en.connectives)}) `)
const PRESENT = new RegExp(`^(?:${anyOf(en.present)})$`)

const DECADE_SPAN = { any: [0, 9], early: [0, 3], mid: [4, 6], late: [7, 9] } as const

/** Year-year ranges and spaced hyphens become " to ", leaving ISO dates alone */
const joinRanges = (t: string): string =>
  t.replace(/^(\d{4}) ?- ?(\d{4})$/, '$1 to $2').replace(/ - /g, ' to ')

/** Splits "a to b" into two sides, or returns null */
function sides(t: string): [string, string] | null {
  const [a, b, ...rest] = joinRanges(t).replace(RANGE_START, '').split(CONNECTIVE)
  return a != null && b != null && rest.length === 0 ? [a, b] : null
}

/** A decade as one year at the start or end of a range */
function decadeYear(s: Single & { kind: 'decade' }, edge: 'start' | 'end'): DateParts {
  const [a, b] = DECADE_SPAN[s.part]
  return { year: part(s.decade + (edge === 'start' ? a : b)) }
}

function asRangeEnd(s: Single, edge: 'start' | 'end'): DateParts | null {
  if (s.kind === 'date') return s.parts
  if (s.kind === 'decade') return decadeYear(s, edge)
  return null
}

const notUnderstood = { error: message('not-understood') } as const

/** Parses an event date typed in words: "about 1965", "late 1940s", "before 1931" */
export function parseText(text: string, config: Config): TextResult<EventState> {
  const t = normalise(text)
  if (!t) return { error: message('empty') }

  const directional = (
    dir: 'before' | 'after',
    side: string | undefined,
  ): TextResult<EventState> | null => {
    const p = side == null ? null : parseSingle(side, config)
    if (!p) return null
    if ('error' in p) return p
    const at = asRangeEnd(p.value, dir === 'before' ? 'end' : 'start')
    return at ? { state: { kind: 'beforeAfter', dir, at }, notes: p.notes } : null
  }
  const after =
    directional('after', AFTER.exec(t)?.[1]) ?? directional('after', ONWARDS.exec(t)?.[1])
  if (after) return after
  const before = directional('before', BEFORE.exec(t)?.[1])
  if (before) return before

  const single = parseSingle(t, config)
  if (single && 'error' in single) return single
  if (single) {
    const v = single.value
    const state: EventState = v.kind === 'date' ? { kind: 'date', parts: v.parts } : v
    return { state, notes: single.notes }
  }

  const pair = sides(t)
  if (pair) {
    const a = parseSingle(pair[0], config)
    const b = parseSingle(pair[1], config)
    if (a && 'error' in a) return a
    if (b && 'error' in b) return b
    const from = a && asRangeEnd(a.value, 'start')
    const to = b && asRangeEnd(b.value, 'end')
    if (a && b && from && to)
      return { state: { kind: 'between', from, to }, notes: [...a.notes, ...b.notes] }
  }
  return notUnderstood
}

function asEndpoint(s: Single, edge: 'start' | 'end'): Endpoint {
  if (s.kind === 'unknown') return { kind: 'unknown' }
  if (s.kind === 'date') return { kind: 'date', parts: s.parts }
  if (s.part === 'any') return { kind: 'decade', decade: s.decade }
  return { kind: 'date', parts: decadeYear(s, edge) }
}

/** Parses one side of a period: a date, "present", or "unknown" */
function parseSide(
  side: string,
  edge: 'start' | 'end',
  config: Config,
): TextResult<Endpoint> | null {
  if (PRESENT.test(side)) return { state: { kind: 'open' }, notes: [] }
  const p = parseSingle(side, config)
  if (!p) return null
  if ('error' in p) return p
  return { state: asEndpoint(p.value, edge), notes: p.notes }
}

/** Parses a period typed in words: "about 1890 to 1905", "June 1975 to present", "since 2004" */
export function parsePeriodText(text: string, config: Config): TextResult<PeriodState> {
  const t = normalise(text)
  if (!t) return { error: message('empty') }

  const build = (
    start: TextResult<Endpoint> | null,
    end: TextResult<Endpoint> | null,
  ): TextResult<PeriodState> | null => {
    if (!start || !end) return null
    if ('error' in start) return start
    if ('error' in end) return end
    return {
      state: { kind: 'period', start: start.state, end: end.state },
      notes: [...start.notes, ...end.notes],
    }
  }
  const open = { state: { kind: 'open' }, notes: [] } as const
  const unknown = { state: { kind: 'unknown' }, notes: [] } as const

  const sinceSide = AFTER.exec(t)?.[1] ?? ONWARDS.exec(t)?.[1]
  const since = sinceSide == null ? null : build(parseSide(sinceSide, 'start', config), open)
  if (since) return since
  const untilSide = BEFORE.exec(t)?.[1]
  const until = untilSide == null ? null : build(unknown, parseSide(untilSide, 'end', config))
  if (until) return until

  const pair = sides(t)
  if (pair) {
    const both = build(parseSide(pair[0], 'start', config), parseSide(pair[1], 'end', config))
    if (both) return both
  }

  // A lone expression: "the 1920s" is the whole decade, a date is both ends
  const p = parseSingle(t, config)
  if (!p) return notUnderstood
  if ('error' in p) return p
  const v = p.value
  if (v.kind === 'decade') {
    const [a, b] = DECADE_SPAN[v.part]
    const start: Endpoint = { kind: 'date', parts: { year: part(v.decade + a) } }
    const end: Endpoint = { kind: 'date', parts: { year: part(v.decade + b) } }
    return { state: { kind: 'period', start, end }, notes: p.notes }
  }
  const e = asEndpoint(v, 'start')
  return { state: { kind: 'period', start: e, end: e }, notes: p.notes }
}
```

````markdown
# edtf-input-core

The model, generator, natural-language parser and bounds behind [`<edtf-input>`](../element). No DOM, so it runs anywhere: browsers, Node, tests.

```ts
import { generate, parseText, resolveConfig } from 'edtf-input-core'

const config = resolveConfig({ semantics: 'event', locale: 'en-NZ', max: 'today' })

const parsed = parseText('about 1965', config)
if (!('error' in parsed)) {
  const result = generate(parsed.state, config)
  result.value // '1965~'
  result.label // 'circa 1965'
  result.earliest // '1965-01-01'
  result.latest // '1965-12-31'
}
```

## API

| Function                        | Does                                                                                   |
| ------------------------------- | -------------------------------------------------------------------------------------- |
| `resolveConfig(input)`          | Fills in defaults. Accepts attribute-style strings (`max: 'today'`, `maxLevel: '1'`).  |
| `generate(state, config)`       | Guided UI state → `Result`. Every value is checked with edtf.js before it is returned. |
| `parseText(text, config)`       | Event text ("late 1940s", "before 1931") → `{ state, notes }` or `{ error }`.          |
| `parsePeriodText(text, config)` | Period text ("about 1890 to 1905", "since 2004") → `{ state, notes }` or `{ error }`.  |
| `analyse(value, config)`        | Checks and describes a raw EDTF value (advanced mode, or a value loaded from a host).  |
| `bounds(value)`                 | Earliest and latest possible days, worked out from the parse tree.                     |

A `Result` has a `status` of `valid`, `incomplete` or `invalid`, plus `value`, `level`, `label`, `caption`, `earliest`, `latest`, `start` and `end` (`date`, `open` or `unknown`), `warnings`, `notes` and `error`. Messages are `{ code, params, text }`: `text` is English, and `code` is there so hosts can localise.

### Config

| Field       | Default      | Notes                                                                                            |
| ----------- | ------------ | ------------------------------------------------------------------------------------------------ |
| `semantics` | `'event'`    | `'event'` (one moment, possibly fuzzy) or `'period'` (a span)                                    |
| `min`/`max` | none         | A year, an ISO date or `'today'`; inclusive                                                      |
| `warn`      | `[]`         | `[{ before: 1826, message: '…' }]`: a soft warning when the date is entirely before (or `after`) |
| `maxLevel`  | `2`          | Highest EDTF level accepted                                                                      |
| `locale`    | `'en'`       | Labels (via edtf-humanize) and slash-date order                                                  |
| `terms`     | `{}`         | edtf-humanize term overrides, such as `approximatePrefix` for "around" instead of "circa"        |
| `now`       | `new Date()` | Injectable clock, for `'today'` and two-digit decades                                            |

## Why not just use edtf.js min/max?

edtf.js is the parser and validator here, but its bounds are wrong for several shapes, so `bounds()` works from the parse tree instead: set ranges (`[1667..1672]` gives a max of the end of 1667), long years (`Y170000002` gives `NaN`), and hemisphere seasons (`2001-25` gets the same range as `2001-33`). It also tells open interval ends (`1950/..`) from unknown ones (`1950/`), which edtf.js reports the same way.
````

```markdown
## Changes made during phase 1

Found while building the core; the code and tests are the reference.

- `Certainty` has a fifth value, `both` (`%`), for "about 1965?".
- More edtf.js rules turned up: a season needs a known year (`XXXX-21` is rejected); seasons can't be interval or set ends; two-ended set ranges reject qualifiers in every position, while open-ended sets accept prefix qualifiers only; and an interval's end must _begin_ strictly after its start begins (`1966/196X` and `1965-06/1965` parse, but building them throws). The generator uses a candidate chain (natural form, then prefix form, then unqualified with a warning) rather than hand-coding every set rule.
- Two-sided "between" collapses to a single date when both ends are the same.
- edtf-humanize 0.1.0 lists every member of a set range. Core labels sets that contain ranges itself (each range in the locale's interval wording, joined with its set connectors) until that's fixed upstream.
- In period mode, a lone decade gives `1920/1929` (story §3 and the prototype), not `196` (story §1). "until 1931" gives `/1931` (unknown start), as in the prototype.
- `min`/`max` are inclusive ISO days, not years, so `max="today"` rejects 1 December this year.
- `timeline` is left out of `Result` until phase 2, when the element draws it; `start`/`end` (`date`, `open`, `unknown`) carry what it needs.
- Messages that the design gave as `{ code, params }` also carry English `text`.

### More for edtf-humanize-js

- `en` formats dates US-style ("March 12, 1982"); en-NZ, en-GB and en-AU users need day-first wording.
- `196X` reads as "1960s (year unknown)", so decade-to-decade periods become "1960s (year unknown) to 1980s (year unknown)".
- `/1931` reads as "unknown date to 1931".
```
